# 附录 A 角色卡与职责矩阵模板

## 角色卡（半页纸就够）

```
角色名称:
目的:     这个角色为什么存在
职责:     必须做的几件事
权限:     可以自己决定什么；什么必须找别人
产出:     交出什么证据（澄清清单、评审记录、变更单）
被谁评审:
后备人选:
```

## 职责矩阵示例

R 执行，A 最终负责，C 咨询，I 知会；每行只有一个 A。

| 活动 | 技术负责人 | 开发 A | 开发 B | 测试 | 产品经理 |
|---|---|---|---|---|---|
| 澄清清单维护 | A | R | R | C | C |
| 软件需求评审 | R | R（非作者） | R（非作者） | C | I |
| 软件架构与接口 | A/R | C | C | I | I |
| 需求变更评审 | A | C | C | C | R（提出方） |
| 验证准则确认 | C | C | I | A/R | I |
